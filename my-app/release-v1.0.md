## 4. 发布步骤

1. 记录待发布提交基线、公开站点、时间及两份产物清单，确认前后端兼容。
2. 进入既有环境 → 静态网站托管 → 文件管理。核对根目录，保留 __auth/、cloud-admin/ 及现有资源。
3. 先上传本次 dist/assets 内的资源到云端 assets/，保留文件名与相对路径；新资源逐项可读取后才进行下一步。
4. 最后将本次 dist/index.html 覆盖到托管根目录 index.html。根目录直接是 index.html 和 assets/，不能多嵌套一层 dist/。
5. 只上传该静态产物，不上传源码、.env、日志、node_modules、云函数包或数据备份。不执行清空目录或删除旧资源。
6. 按下一节验证；若失败，保存原始证据，依 [回滚手册](rollback-manual.md) 恢复旧入口。上传成功提示不能代替公网验证。

上述控制台文件上传能力见 [CloudBase 静态资源管理](https://docs.cloudbase.net/hosting/manage)；本项目采用现有文件上传路径，不假定有部署历史一键回退。
